## Professional Self-Assessment

  The SNHU cybersecurity program has taught me a lot about coding and helped me narrow down my career goals! When I initially started my classes, I only had the broad goal of “working with software”. I knew the basics of a few coding languages and I knew that I wanted to learn more, but I didn’t have many specific goals beyond that. This program taught me a lot about coding and best practices around working with software, but it also helped me narrow down what specifically I love about computers. I really enjoy cybersecurity: learning about previous hacks and known vulnerabilities, penetration testing, helping people make their code more secure, etc. While understanding how to develop software is definitely an important skill for anyone working within software systems, it’s actually not the part I enjoy most. I prefer to work with preexisting code and modify it, it feels a bit like solving puzzles to me! I am grateful to this program for helping me discover my love of hacking. 

  I found this program to be very helpful for the professional/interpersonal aspect of things, as well. While I consider myself to be quite friendly, I don’t always work well with others professionally. I have a hard time with social cues, understanding what is expected of me in different scenarios. I generally find it much easier to just try to complete everything on my own, but an important part of working with software systems is being able to communicate and work with others effectively. Several of my courses in this program had assignments involving giving presentations or writing emails to stakeholders, business executives, etc. This was a challenge for me, but I’m very grateful for the practice! I feel much more sure of my abilities to communicate with stakeholders and work within a team environment now that I have practiced it and gotten feedback on best practices in these types of environments.
  
  I love data structures and databases! I think that discrete mathematics is a lot of fun, and a lot of what I learned about matrices came in handy when learning about storing data (hash tables, trees, etc.) While software engineering is not my primary interest, I do think it can be fun at times! I have a personal goal of getting skilled enough at C coding that someday I can enter into the Intentionally Obfuscated C Code Contest (IOCCC), which definitely requires foundational coding knowledge. I think that SNHU taught me a lot about best practices in software development! Honestly, I had never even made a proper code flowchart before starting this program. I also learned quite a bit about secure coding practices! It’s important to learn how to write secure code, not just how to find vulnerabilities in existing code. I think that learning is a lifelong process and I look forward to learning more about cybersecurity. Lately, I’ve been having a lot of fun playing around with Burpsuite and learning how to use all the built-in tools in Kali Linux. While I’m certainly far from an expert, I think that this course has given me a good foundation of computer science knowledge to build off. 
  
_Also, on a personal note, I feel proud to be the first person in my family to get a Bachelor’s degree, especially as a developmentally disabled woman in a STEM field! :-) I have worked hard to get here and am terribly grateful to all my teachers and my counselor for helping me out._


### Enhancements

  The CS 499 capstone class specifically has helped me practice updating and enhancing my code on previously completed projects. It has been a fun experiment to return to old assignments with more knowledge and find ways to improve them! Building an ePortfolio allowed me to display my skills and strengths in a nicely formatted way. I may be able to use this ePortfolio (with the addition of a cover letter) in future job applications. Each artifact here showcases a different skillset. My enhancements on artifact one show my understanding of software engineering and design, my enhancements on artifact two display my familiarity with algorithms and data structures, and my enhancements on artifact three show my experience with databases. 
  
  The first artifact I enhanced was my final project from CS 330: Computational Graphics and Visualization. This artifact showcases my ability to design and depict a scene digitally. I decided to improve this by optimizing my code to make the functions run faster. I did this by reducing per-frame shader render loops, which were inefficient. I added a cached render-item list so that items could simply be called upon rather than re-rendered for manual setup of each frame. The original can be found 
  [here](https://github.com/cryptidcatcher/cryptidcatcher.github.io/blob/Initial-Artifacts/CS-330-Portfolio-main.zip)  and the enhancement can be found 
  [here](https://github.com/cryptidcatcher/cryptidcatcher.github.io/blob/Enhancements/CS-330-Portfolio-main-2.zip) 
  
  
  The second artifact was my final project from CS 320: Software Testing, Automation, and Quality Assurance. For this enhancement, I wanted to show my understanding of algorithms and data structures.  First, I fixed obvious errors within the code. ContactService had the wrong package declaration and some broken logic and the appointmentService was broken too, so I fixed those. There was a package mismatch in contactService that I took care of, also. Then I created the appointmentService.java and taskService class to streamline the data and make it quicker and more efficient/logical. The original can be found 
  [here](https://github.com/cryptidcatcher/cryptidcatcher.github.io/blob/Initial-Artifacts/CS320ProjectOne.zip) and the enhancement can be found 
  [here](https://github.com/cryptidcatcher/cryptidcatcher.github.io/blob/Enhancements/CS320ProjectOne%202.zip) .
  
  The third artifact was meant to demonstrate my understanding of databases. For this enhancement, I used my final project from CS 340: Advanced Programming Concepts. I decided to add In-Memory Caching and Custom Data Structures. I wanted to integrate a custom search-tree algorithm or implement an in-memory caching mechanism using nested dictionaries/hashmaps with the hope of reducing repeated database queries. he original can be found [here](https://github.com/cryptidcatcher/cryptidcatcher.github.io/blob/Initial-Artifacts/CS340%20Project%20Two%20Jasmine%20Procaccini.zip) and the enhancement can be found [here](https://github.com/cryptidcatcher/cryptidcatcher.github.io/blob/Enhancements/CS340%20Enhanced%20Jasmine%20Procaccini.zip).
